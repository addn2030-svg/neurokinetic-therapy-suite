# 🤖 حزمة التصدير إلى Gemini — رئيس المكتب الرقمي

هذه الحزمة تحوّل وكيل "رئيس المكتب" الحالي (المبني على بايثون) إلى
**تعليمات نظام + معرفة + سياق ديناميكي** تعمل داخل Gemini (Gem أو AI Studio).

## محتويات الحزمة

| الملف | الوظيفة |
|---|---|
| `system_instruction.md` | الرسالة/التعليمات النظامية الجاهزة للصق في حقل System Instructions |
| `removal_checklist.md` | قائمة العناصر التي يجب إزالتها حتماً قبل أي رفع |
| `knowledge/` | ملفات المهارات التي تُرفع كـ RAG (قائمة الملفات في الداخل) |

## خطوات الاستيراد في Gemini

1. **نفّذ `removal_checklist.md` بنداً بنداً أولاً.**
2. افتح Gemini → **Gems → إنشاء Gem جديد**.
3. الصق محتوى `system_instruction.md` في حقل *System Instructions*.
4. ارفع ملفات `knowledge/` كملفات معرفة (Knowledge Files).
5. اختبر الـ Gem بسيناريوهات `training/rcjy-chief-of-staff-scenarios.md` كحالات تقييم (ضعها في ورقة اختبار منفصلة — لا ترفعها كمعرفة).
6. يومياً: ألصق سياق اليوم الديناميكي الذي يولده n8n (المهام المفتوحة + المتأخرات) في بداية المحادثة.

## ربط الحزمة بالبنية الجديدة

```
n8n (Railway) ── يقرأ ──► Supabase + ورقة المهام
      │
      ├─ 6:00 صباحاً: يبني "سياق اليوم" ويرسله لتيليجرام/الإيميل ← تلصقه في Gemini
      └─ عند كل رسالة: يستدعي Gemini API بالتعليمات أعلاه ويرد عبر تيليجرام
```
