# 📚 ملفات المعرفة (Knowledge / RAG)

ضع في هذا المجلد النسخ **المُجهّلة من البيانات الحساسة** من ملفات المهارات التالية،
ثم ارفعها إلى Gemini Gem كملفات معرفة حتى يبحث فيها الوكيل عند الحاجة فقط
(بدل تضخيم الـ System Prompt):

| الملف | المحتوى | ملاحظات قبل الرفع |
|---|---|---|
| `clinical-intelligence.md` | بروتوكولات التحليل السريري | إزالة أي بيانات مرضى حقيقية |
| `negotiation.md` | أساليب وبروتوكولات التفاوض | إزالة أسماء الأطراف الحقيقية |
| `health-protocols.md` | بروتوكولات الصحة الشخصية | بيانات المستخدم العامة فقط |
| `travel-management.md` | إدارة السفر والحجوزات | بدون أرقام جوازات/حجوزات فعلية |
| `financial-rules.md` | قواعد الميزانية العامة | نسب وسياسات فقط — بدون أرقام حسابات |
| `SKILL.md` (NKT) | مواصفة خبير العلاج العصبي الحركي | موجود بالفعل في جذر هذا المستودع — آمن للرفع |

## قواعد عامة
1. كل ملف يُرفع هنا يجب أن يجتاز `removal_checklist.md` أولاً.
2. يُفضل أن يبدأ كل ملف بعنوان ودور موجز: "أنت تستدعي هذه المعرفة عندما…".
3. لا تضع في هذه الملفات أي توكن أو مفتاح أو سلسلة اتصال قاعدة بيانات.
